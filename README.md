# Blog Mon Impôt Zen (monimpotzen.com)

Site Jekyll publié par GitHub Pages. Produit et alimenté par le skill « Mon Marketing MIZ » de Claude.

- Nouvel article : fichier `_posts/AAAA-MM-JJ-titre-en-minuscules.md` avec `title`, `description`, `chapo`, `cible` en tête. Publié automatiquement après chaque commit sur `main`.
- Liens (Calendly, réseaux), pixel Meta et vérification de domaine : `_config.yml`.
- Le pixel n'est chargé qu'après accord de l'internaute (`_includes/consentement.html`).
- Toute publication passe la grille de conformité MIZ (pas de conseil personnalisé, pas de promesse de gain, pas de mode d'emploi détaillé).
